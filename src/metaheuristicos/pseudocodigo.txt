================================================================================
ALGORITMO HÍBRIDO PARALELIZADO: AG + GWO 
PARA OPTIMIZACIÓN DE HIPERPARÁMETROS DE UNA RED NEURONAL MLP
================================================================================

ENTRADA:
    X_train, y_train        // Datos de entrenamiento
    X_val, y_val            // Datos de validación
    N = 20                  // Tamaño de la población de lobos
    MaxIter = 30            // Número máximo de iteraciones
    ProbCruce = 0.8         // Probabilidad de cruce genético
    ProbMutacion = 0.15     // Probabilidad de mutación genética

SALIDA:
    Alpha                   // Mejor solución matemática encontrada (Hiperparámetros)
    HistorialFitness        // Registro de evolución (estadísticas por iteración)

--------------------------------------------------------------------------------
FASE 0: DEFINICIÓN DEL GENOMA (INDIVIDUO LOBO)
--------------------------------------------------------------------------------
Cada Lobo es un vector que representa los hiperparámetros de un MLP:
    n_neuronas_capa1       ∈ [10, 200]
    n_neuronas_capa2       ∈ [0, 200] (0 = sin segunda capa)
    activacion             ∈ {relu, tanh, logistic}
    solver                 ∈ {adam, sgd}
    alpha                  ∈ [0.0001, 0.1]
    learning_rate_init     ∈ [0.0001, 0.1]
    batch_size             ∈ {16, 32, 64, 128, 256}
    max_iter               ∈ [100, 500]


--------------------------------------------------------------------------------
FASE 1: INICIALIZACIÓN Y EVALUACIÓN PARALELA
--------------------------------------------------------------------------------
1. Crear población Poblacion[0..N-1] con genes aleatorios válidos.
2. EN PARALELO (usando todos los núcleos disponibles):
       PARA cada Lobo en Poblacion:
           Lobo.fitness ← EVALUAR_FITNESS(Lobo, X_train, y_train, X_val, y_val)
       FIN PARA

3. ORDENAR Poblacion POR fitness DESCENDENTE.
4. ASIGNAR Jerarquía GWO:
       Alpha ← Poblacion[0]    (Mejor solución)
       Beta  ← Poblacion[1]    (Segunda mejor)
       Delta ← Poblacion[2]    (Tercera mejor)


--------------------------------------------------------------------------------
FASE 2: CICLO PRINCIPAL HÍBRIDO (ITERATIVO)
--------------------------------------------------------------------------------
PARA iter ← 1 HASTA MaxIter:

    // Factor de convergencia lineal (decrece de 2 a 0 a lo largo del tiempo)
    a ← 2 - 2 * (iter / MaxIter)

    // ─── ETAPA 1: ALGORITMO GENÉTICO (EXPLORACIÓN GLOBAL) ───
    NuevaPoblacion ← lista vacía
    AGREGAR Alpha, Beta, Delta a NuevaPoblacion // (Elitismo puro)

    MIENTRAS tamaño de NuevaPoblacion < N:
        Padre1 ← SELECCIÓN_TORNEO(Poblacion)
        Padre2 ← SELECCIÓN_TORNEO(Poblacion)
        
        SI aleatorio(0,1) < ProbCruce:
            Hijo1, Hijo2 ← CRUCE_UNIFORME(Padre1, Padre2)
        SINO:
            Hijo1, Hijo2 ← Padre1, Padre2
        
        MUTAR(Hijo1, ProbMutacion)
        MUTAR(Hijo2, ProbMutacion)
        
        AGREGAR Hijo1, Hijo2 a NuevaPoblacion
    FIN MIENTRAS

    Poblacion ← NuevaPoblacion[0..N-1]

    // ─── ETAPA 2: OPTIMIZACIÓN DE LOBOS GRISES (EXPLOTACIÓN LOCAL) ───
    // Se ajustan las posiciones de los lobos "Omega" guiándose por Alpha, Beta y Delta
    PARA cada lobo Omega EN Poblacion (índices 3 a N-1):
        PARA cada gen j del lobo:
            // Calcular atracción matemática hacia líderes usando factores estocásticos r1, r2
            X1 ← CALCULAR_ATRACCIÓN(Alpha.gen[j], Omega.gen[j], a)
            X2 ← CALCULAR_ATRACCIÓN(Beta.gen[j],  Omega.gen[j], a)
            X3 ← CALCULAR_ATRACCIÓN(Delta.gen[j], Omega.gen[j], a)
            
            // Promediar distancias para converger
            Omega.gen[j] ← (X1 + X2 + X3) / 3
            Omega.gen[j] ← REDONDEAR_Y_AJUSTAR_LIMITES( Omega.gen[j] )
        FIN PARA
    FIN PARA

    // ─── ETAPA 3: RE-EVALUACIÓN PARALELA ───
    EN PARALELO (usando JobLib multi-core):
        PARA cada Lobo en Poblacion:
            Lobo.fitness ← EVALUAR_FITNESS(Lobo)
        FIN PARA

    // ─── ACTUALIZAR JERARQUÍA Y ESTADÍSTICAS ───
    ORDENAR Poblacion POR fitness DESCENDENTE
    Alpha ← Poblacion[0]
    Beta  ← Poblacion[1]
    Delta ← Poblacion[2]

    REGISTRAR_ESTADÍSTICAS(iter, Alpha, Poblacion)

FIN PARA


--------------------------------------------------------------------------------
FASE 3: FUNCIONES AUXILIARES DE SOPORTE
--------------------------------------------------------------------------------

FUNCIÓN EVALUAR_FITNESS(Lobo):
    1. Decodificar genes del Lobo a parámetros de Scikit-Learn.
    2. Instanciar MLPClassifier con dichos hiperparámetros y RandomState fijo.
    3. Entrenar(X_train, y_train).
    4. fitness = Calcular Accuracy(X_val, y_val).
    5. RETORNAR fitness.

FUNCIÓN SELECCIÓN_TORNEO(Poblacion):
    1. Seleccionar aleatoriamente dos lobos distintos.
    2. RETORNAR el lobo con el fitness más alto.

FUNCIÓN CRUCE_UNIFORME(Padre1, Padre2):
    PARA cada gen k:
        SI aleatorio(0,1) < 0.5:
            Heredar gen k de Padre 2 a Hijo 1
        SINO:
            Heredar gen k de Padre 1 a Hijo 1
    RETORNAR Hijo1, Hijo2

FUNCIÓN MUTAR(Lobo, ProbMutacion):
    PARA cada gen k:
        SI aleatorio(0,1) < ProbMutacion:
            SI es gen continuo   -> Aplicar perturbación Gaussiana
            SI es gen entero     -> Reasignación aleatoria uniforme en su rango
            SI es gen categórico -> Nueva categoría aleatoria
    RETORNAR Lobo
